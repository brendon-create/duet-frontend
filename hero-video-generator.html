⚠ 需要透過 HTTP 伺服器開啟

此工具使用 fetch() 載入字體資料，在 file:// 協議下會被瀏覽器的安全政策封鎖（CORS）。
請啟動一個本機 HTTP 伺服器後重新開啟。

① 在終端機切換到 frontend 資料夾：
cd /Users/brendonchen/Desktop/Duet-code/frontend
點擊複製
② 啟動本機伺服器（Python 3，通常已預裝）：
python3 -m http.server 8080
點擊複製
③ 在瀏覽器開啟：
http://localhost:8080/hero-video-generator.html
點擊複製

若沒有 Python：可使用 VS Code 的 Live Server 外掛，或執行 npx serve .（需 Node.js）。
